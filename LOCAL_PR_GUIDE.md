# Local pull-request simulation

This repository contains 100 feature branches, each with a distinct outfit scenario commit, merged with `git merge --no-ff`. These are **not** hosted pull requests and cannot honestly satisfy a check requiring GitHub/GitLab PR records.

Run `python -m vogue_engine.offline_style_catalog.validate_catalog` to validate all scenarios. See `LOCAL_PR_RECORDS.json` for traceability.
