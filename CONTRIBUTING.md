# Contributing to Vogue Engine

Contributions should address a concrete issue and include tests for behavior changes.

1. Fork the repository and create a branch named `feature/<short-topic>`.
2. Make a focused code change with a descriptive commit message.
3. Run `python -m unittest tests.test_offline_planner -v` and `python verify_project.py`.
4. Push the branch to a hosted GitHub or GitLab repository.
5. Open a pull request describing the problem, approach, test evidence, and risks.
6. Request review and merge only after review and passing checks.

**Evidence note:** local Git commits and merges are not hosted pull requests. A PR count can only be verified from the GitHub/GitLab service (or an authentic exported PR record). This ZIP does not claim to contain 100 hosted PRs.

Existing history includes programmatically created integration commits from prior packaging. Their presence alone does not establish 100 independently reviewed contributions.
